# Dataset Download Instructions

## ISOT Fake News Dataset (Recommended)

1. Download from Kaggle: https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
2. Extract and place the files here:
   - `data/True.csv`
   - `data/Fake.csv`

## WELFake Dataset (Alternative — single CSV, larger)

1. Download from Kaggle: https://www.kaggle.com/datasets/saurabhshahane/fake-news-classification
2. Place `WELFake_Dataset.csv` in this directory.

## GloVe Embeddings (Optional but Recommended)

1. Download `glove.6B.zip` from: https://nlp.stanford.edu/projects/glove/
2. Extract `glove.6B.100d.txt` into this directory.
